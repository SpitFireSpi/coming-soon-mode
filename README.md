# Coming Soon Mode

A WordPress maintenance mode plugin that displays a Coming Soon message to website visitors.

**Type:** Plugin  
**Author:** Charlie Vazquez  
**Course:** COSW 240  
**Version:** 0.1.0

## Overview

Coming Soon Mode is a WordPress plugin that allows administrators to display a Coming Soon or maintenance message while their website is being developed or updated.

The goal is to give visitors a professional message explaining that the website is temporarily unavailable while administrators continue working behind the scenes.

## Planned Features

- Coming Soon / Maintenance Mode toggle
- Customizable background image and message
- Notification signup for visitors
- Contact Us button
- Timer showing how long the site has been in maintenance mode

## How It Will Work

### For Visitors

Visitors will see a Coming Soon page with a background image, message, timer, notification signup, and Contact Us option.

### Behind the Scenes

Administrators will be able to enable or disable Coming Soon Mode through the WordPress dashboard.

The plugin will use PHP for WordPress functionality, CSS for styling, and JavaScript for interactive features.
